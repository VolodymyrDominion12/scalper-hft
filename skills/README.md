# Скіли проєкту scalper-hft

Скіли — це перевірені процедури для агентів (AI-асистентів) і розробників.
Кожен скіл = markdown з метою, кроками та критеріями завершення.

## Зміст

- [strategy-development.md](strategy-development.md) — створення нової стратегії за стандартом проєкту
- [backtest-run.md](backtest-run.md) — запуск і інтерпретація бектесту
- [overfitting-audit.md](overfitting-audit.md) — аудит стратегії на перенавчання
- [data-management.md](data-management.md) — завантаження та кешування даних
- [hft-risk-execution](../.agents/skills/hft-risk-execution/SKILL.md) — контроль ризиків, sizing та paper/live торгівля

> Всі процедури також оформлені як нативні скіли для AI-асистента в `.agents/skills/<name>/SKILL.md`.
