## 🛠️ Раніше виявлені, але ВЖЕ ВИПРАВЛЕНІ баги

### 1. `risk_of_ruin` (Виправлено)
**Файл:** `scalper_hft/backtest/metrics.py`
Формула раніше була некоректною. Наразі реалізовано правильний експоненційний розрахунок ймовірності розорення на основі Келлі:
`math.exp(-2.0 * avg_trade_return / (sigma_trade * sigma_trade))`

### 2. `compute_metrics` annualization (Виправлено)
**Файл:** `scalper_hft/backtest/metrics.py`
Раніше масштаб завжди був хвилинним. Тепер масштаб динамічно обчислюється через медіану між барами (`delta_s`), що дозволяє коректно відображати Sharpe для 1h чи будь-яких інших таймфреймів.

### 3. `estimate_spread_from_bookticker` (Виправлено)
**Файл:** `scalper_hft/backtest/execution.py`
Виправлено неправильний fallback на `bid_qty`/`ask_qty`.

### 4. `HedgeBlend.step()` (Виправлено)
**Файл:** `scalper_hft/strategies/blend.py`
`eta` більше не фіксується статично. Значення правильно розраховується та адаптується.

### 5. `pair_legs` (Виправлено)
**Файл:** `scalper_hft/live/risk_gate.py`
Безпечно відрізає суфікс через `clean_pid = pid.rsplit(":", 1)[0] if ":" in pid else pid`.
