**Висновок 3b:** на 365д 1d-структура майже константна → htf1d-варіанти ідентичні

із senior-TF гейтингом. MTF-структура — корисний інструмент для довших горизонтів
(де 4h/1d тренд живе), а не панацея для 1h.

## Підсумок ітерації 3 (чесний)
1. Горизонтний ефект відтворено: 1d supertrend:ls +0.50 avg OOS (6–8 позитивних
   символів, 60–80% вікон) проти −0.55 на 4h того ж механізму.
2. Статистичний бар проєкту не пройдено: 5–12 OOS угод на 1d (бар ≥40),
   DSR=0 при n_trials≈2.04M (добуток param_space × 50).
3. Напрямковий «високочастотний» шар на 1h/4h у цій структурі ринку не має
   підтвердженого edge; валідований позитив — relative value (pairs_arb 1h maker).

## План ітерації 4
1. Портфельна рамка: 1d trend sleeve (supertrend, low-freq) + pairs_arb 1h maker
   (валідований) + regime-шар зверху (перемикання/risk).
2. Збільшення вибірки 1d-кандидата: довша історія (5y) або 12h/8h компроміс.
3. Переоцінка бару аудиту: n_trials для параметрів, що НЕ оптимізувались
   (дефолтні), проти добутку param_space — інакше DSR недосяжний навіть для
   валідованих пар (документувати окремо).
