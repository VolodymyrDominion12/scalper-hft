# G5 Time Stop Bake-off Report

## Опис
Мета: Перевірити гіпотезу про те, що примусовий вихід (time_stop) по досягненню тривалості позиції > N × half-life покращує результати стратегії `pairs_arb`.

## Конфігурація
- **Пара:** LINKUSDT / BTCUSDT
- **Інтервал:** 1h
- **Глибина:** 1095 днів (3 роки)
- **Комісії:** Maker (post-only)

## Результати

| Метрика | Baseline (time_stop=False) | Experiment (time_stop=True) |
| --- | --- | --- |
| **Sharpe (annual)** | 0.362 | 0.140 |
| **maxDD** | -2.93% | -2.91% |
| **Дохідність** | +2.10% | +0.71% |
| **Win rate** | 70.83% | 50.00% |
| **Profit factor** | 1.356 | 1.114 |
| **Угоди** | 72 | 94 |
| **Експозиція** | 52.38% | 36.44% |

## Висновок
Введення `time_stop` призвело до значного падіння Sharpe ratio (ΔSharpe = -0.222), падіння win rate на 20% і зменшення загального прибутку. Хоча експозиція зменшилась, а maxDD залишився майже без змін (-2.91% замість -2.93%), примусове закриття позицій обрізає прибуткові угоди, які потребують більше часу для сходження спреду.

**Статус:** **FAIL**
Гіпотеза відхилена. Використання `time_stop` для даної стратегії на цих параметрах недоцільне і має бути вимкнено за замовчуванням.
