## Чесні обмеження

1. **Вибірка**: 28–47 угод/рік — достатньо для первинного висновку, але не для
   впевненості 95%; потрібен paper-прогін у реальному часі.
2. **Maker-виконання обов'язкове** (taker значно гірший).
3. **Пари з сильними відносними трендами** (SOL, BNB/DOGE vs ETH) не ревертуються
   у межах lookback — виключати.
4. XRP/BTC при ez=2.0/lb=480 має лише 28 угод — при розгортанні розглянути
   портфель з BTC/ETH для диверсифікації режимів.

## Висновок

Портфель парних кандидатів: **XRP/BTC + BTC/ETH** (1h, maker post-only).
Розгортати у paper, моніторити місячну концентрацію та відносні тренди
(щотижневий аудит).
