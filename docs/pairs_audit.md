## Чесні обмеження

1. **Концентрація прибутку**: 2/3 річного PnL дали 3 місяці Q4 2025 — edge
   режимно-залежний (сильні реверсії відносного спреду).
2. **Вибірка**: 47 угод/рік — достатньо для первинного висновку, але не для
   впевненості 95%.
3. **Maker-виконання обов'язкове** (taker: +1.17% за 180д проти +2.64% maker).
4. **SOL-пари** страждають від тривалих відносних трендів (не ревертуються
   у межах lookback).

## Висновок

BTC/ETH pairs_arb (1h, maker) — **єдиний кандидат, що пройшов річну валідацію**:
позитивний IS+OOS, помірний профіль ризику. Рекомендація: розгортати у paper
з maker post-only, моніторити місячну концентрацію, тримати стоп на режим
(зупинка при N місяців поспіль збитку).
