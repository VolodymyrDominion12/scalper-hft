## Інтерпретація

1. **Вікно edge**: ранній 2024 (ETF-ралі) — фандінг 10–13% річних, 9–19% періодів
   перевищували 36% річних. Там funding arb мав би працювати.
2. **З квітня 2024**: фандінг структурно низький (2–8% річних, 0% точок >36%).
   Причина: зрілість ринку, зник преміум-перекіс лонгів, зростання пропозиції перпів.
3. **Наслідок для системи**: funding_carry та funding_arb з порогами 0.00006/8h
   (≈22% річних) у поточному режимі НЕ генерують сигналів — вони "сплять" за
   дизайном. Це не баг: це режимний фільтр.
4. **Щоб arb був життєздатним**, потрібно:
   - регім-гейт: вмикати лише коли спостережуваний фандінг > ~10% річних кілька тижнів;
   - maker-виконання (post-only) на обох ногах;
   - контроль basis-ризику (basis_std 1–2.4 bps на Binance — малий, але враховувати).
5. **Практична рекомендація**: на поточному ринку funding-стратегії НЕ розгортати.
   Моніторити фандінг щотижнево (weekly-audit workflow вже це робить через funding
   у звітах) — при появі високого режиму стратегії активуються автоматично
   (поріг входу перетинається).

## Куди далі

- Basis-торгівля (премія перп−спот): basis_std 1–2.4 bps — вузький, потребує
  чесного бектесту (див. funding_arb висновки).
- Maker post-only виконання для будь-яких carry-структур.
